# 📊 Customer-Segementation-Dashboard(Excel)
Excel-Based customer segmentation dashboard using RFM analysis and Business Intelligence techniques.

🎯 Objective

To analyze customer data and build an interactive Excel dashboard that segments customers based on behavior, demographics, and satisfaction, enabling data-driven business decisions.

---

🛠 Tools Used

- Microsoft Excel (Advanced)
- Pivot Tables & Pivot Charts
- Data Cleaning Functions (TRIM, PROPER , IF ,IFS)
- RFM Analysis (Recency, Frequency, Monetary)
- Conditional Formatting (Heatmaps)
- VBA Automation

---

📂 Dataset Description

The dataset includes:

- Customer demographics (Age, Region, Income)
- Transaction data (Purchase frequency, Spending)
- Customer behavior (Engagement, Channel)
- Survey data (Satisfaction & Recommendation score)

---

🚀 Features

- Dynamic KPI Cards ( Total Customers, Revenue, Average Order Value, Repeat %)
- RFM-based Customer Segmentation
- Demographic Analysis (AgeGroup & Income)
- Interactive Dashboard with Slicers
- Monthly Revenue Trend Analysis
- Segment Distribution(Donut Chart)
- Satisfaction Heatmap(Region x Channel)

---
⚙️ Automation
- One-click dashboard refresh using VBA
- Automatically updates all Pivot Tables
- Refreshes all data connections
- Displays last updated timestamp

----


📈 Key Insights

- High-value customers contribute majority of revenue
- Certain regions show higher satisfaction and retention
- At-risk customers identified using low frequency & high recency
- Income levels signficantly influence customer spending behavior

---
💼 Business Value
- Identifies high-value customers for targeted marketing
- Helps detect at-risk customers for retention strategies
- Enables data-driven decision-making
- Improves customer segmentation for business growth
